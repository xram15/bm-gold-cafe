# 👑 BM GOLD — Menu Interactif Digital & Espace VIP

Menu interactif digital sous forme de livre de luxe pour le café lounge **BM GOLD**.

## 🌟 Fonctionnalités

- **Livre Numérique Interactif :** Tournage de page avec effet physique réaliste (Page Curl 3D).
- **Design de Luxe :** Thème or et noir, typographie prestigieuse (*Svetze*, *Montserrat*), vidéo d'accueil d'ambiance et appliques murales dorées.
- **Espace Gérant & Administration Sécurisé :**
  - Authentification réelle avec Supabase.
  - Gestion dynamique par page des produits (ajout, modification, suppression, prix).
  - Gestion des photos du menu.
  - Gestion des administrateurs et réinitialisation de mot de passe.
  - Bouton **Enregistrer** avec double synchronisation : Stockage local persistant + Cloud Supabase.
- **Déploiement Web Ultra-Rapide :** Hébergé sur Firebase Hosting.
- **Accès Client Simplifié :** QR code VIP pour ouverture instantanée sur smartphone.

## 🚀 Liens

- **Site Web en ligne :** [https://bm-gold-cafe-2026.web.app](https://bm-gold-cafe-2026.web.app)
- **Base de données Cloud :** Supabase (`caffe-bm`)

## 🛠️ Stack Technique

- **Framework :** Flutter (Web & Mobile)
- **Backend & Auth :** Supabase (PostgreSQL, Storage, Auth)
- **Hébergement :** Firebase Hosting
- **Animation :** Custom 3D Page Flip, Video Player
